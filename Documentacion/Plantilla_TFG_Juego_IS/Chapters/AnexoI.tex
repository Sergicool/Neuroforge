\chapter{Manual de instalación}

\textit{NeuroForge} está disponible para su descarga a través de un formulario de Google Drive\footnote{\url{https://docs.google.com/forms/d/e/1FAIpQLScm6P6NOzh9SFgDG-yC_Ts5v9lu_q6WPV9RUTJYB488vQDsxA/viewform?usp=header}}, donde se encuentran los ejecutables precompilados para Windows y Linux en formato comprimido, junto con un enlace directo a los archivos.

\textit{NeuroForge} se distribuye como una aplicación de escritorio autocontenida para Windows y Linux. No requiere proceso de instalación ni dependencias externas; basta con descomprimir el paquete de distribución y ejecutar el archivo principal.

\section{Requisitos del sistema}
Antes de ejecutar el videojuego, se recomienda un equipo con las siguientes especificaciones:
\begin{itemize}
	\item \textbf{Sistema operativo:} Windows 10 o Windows 11 (64 bits), o distribución de Linux lanzada a partir de 2018.
	\item \textbf{Procesador:} CPU de doble núcleo a 2,0~GHz o superior.
	\item \textbf{Memoria RAM:} 4~GB.
	\item \textbf{Tarjeta gráfica:} GPU con soporte completo de Vulkan~1.0 (por ejemplo, Intel HD Graphics 510 o superior).
	\item \textbf{Almacenamiento:} 200~MB de espacio libre en disco.
\end{itemize}

\section{Procedimiento de ejecución}

Para poner en marcha el videojuego por primera vez, se deben seguir los siguientes pasos orientados al despliegue del software:

\begin{enumerate}
	\item Descomprimir el archivo comprimido de la distribución (\texttt{NeuroForgeWindows.zip} o \texttt{NeuroForgeLinux.tar.gz}) en el directorio local deseado dentro del sistema de archivos.
	\item Comprobar que el directorio resultante de la extracción contiene la estructura base necesaria para la correcta ejecución del sistema:
	\begin{itemize}
		\item \texttt{NeuroForge.exe} (en entornos Windows) o \texttt{NeuroForge.x86\_64} (en entornos Linux).
		\item \textbf{Carpeta \texttt{Bot}/}:
		\begin{itemize}
			\item \texttt{bot\_inference.py}
			\item \texttt{neuroforge\_bot\_vXXXXXX.zip}
		\end{itemize}
	\end{itemize}
	\item Proceder con el lanzamiento de la aplicación según el sistema operativo anfitrión:
	\begin{itemize}
		\item \textbf{En Microsoft Windows:} Realizar doble clic sobre el archivo ejecutable \texttt{NeuroForge.exe}.
		\item \textbf{En Linux:} Asegurar los permisos de ejecución del binario abriendo una terminal en el directorio y ejecutando el comando \texttt{chmod +x NeuroForge.x86\_64}. Posteriormente, iniciar el juego mediante doble clic o a través de la consola con la instrucción \texttt{./NeuroForge.x86\_64}.
	\end{itemize}
\end{enumerate}

\section{Solución de problemas comunes}

Si el videojuego no arranca o la ventana se cierra inesperadamente al iniciarse, se recomienda verificar que los controladores de la tarjeta gráfica del equipo están actualizados a su última versión y ofrecen soporte completo para la API Vulkan~1.0. En equipos portátiles que dispongan de arquitectura de gráficos híbrida (tarjeta integrada y tarjeta dedicada), puede ser necesario forzar el uso de la GPU de alto rendimiento desde el panel de control del fabricante (NVIDIA Control Panel o AMD Software).

La subcarpeta \texttt{Bot} se encuentra en la misma ruta relativa que el binario ejecutable, manteniendo intactos en su interior tanto el script \texttt{bot\_inference.py} como el archivo comprimido del modelo (\texttt{neuroforge\_bot\_vXXXXXX.zip}) sin modificaciones en sus cadenas de texto. De lo contrario el videojuego seguirá funcionando igualmente pero sin oponente inteligente.
